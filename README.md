Análise do Mercado Brasileiro de Seguros e Previdência

Contexto: Projeto pessoal de análise de dados desenvolvido para aplicar conhecimentos de Power BI a um cenário real do meu setor de atuação — Previdência Privada. Utiliza dados públicos e oficiais da SUSEP (Superintendência de Seguros Privados).

Pergunta de negócio: Como evoluiu o registro de produtos de seguros, previdência e capitalização no mercado brasileiro entre 1997 e 2026, e como o Itaú se posiciona frente aos concorrentes?

O que foi feito:

Tratamento e limpeza dos dados (extração de ano de registro, separação de categorias de ramo)
Criação de medidas DAX para análise comparativa
Construção de dashboard com 4 visualizações: evolução temporal, distribuição por tipo de produto, ranking de empresas (Top 10) e concentração por ramo de atuação

Fonte dos dados: Portal de Dados Abertos do Governo Federal (dados.gov.br) — Consulta de Produtos SUSEP

Ferramentas: Power BI Desktop, DAX, Power Query
